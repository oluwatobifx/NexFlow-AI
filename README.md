# NexFlow AI

A concept website for **NexFlow AI**, an AI operating system for small and medium businesses (SMEs): AI assistant, workflow automation, live analytics, billing and multi-tenant workspaces.

Designed and built by [Oluwatobi Joel](https://tobi-portfolio-murex.vercel.app).

## Pages

| Page | File | URL |
|---|---|---|
| Home | `index.html` | `/` |
| About | `about.html` | `/about` |
| Services | `services.html` | `/services` |
| Contact | `contact.html` | `/contact` |

`styles.css` holds all styles (colors and fonts are at the top), and `main.js` handles the mobile menu, scroll animations, the pricing toggle and the contact form (a demo; it doesn't send messages).

The site is plain HTML, CSS and JavaScript with no build step, and it is fully responsive from small phones (320px) to large desktops. It is hosted on Vercel, and every push to `main` redeploys it.
